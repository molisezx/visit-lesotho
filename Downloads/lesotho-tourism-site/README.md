# Kingdom in the Sky: Lesotho Tourism Website
Principles of Web Design (BIWD2110/DIWD2110), Assignment 1.

Pages: index, destinations, accommodation, activities, gallery, contact (booking + registration).
Stack: HTML5, CSS3 (css/style.css), Bootstrap 5.3 (CDN), JavaScript (js/main.js).
Open index.html in a browser to run it. No build step.
